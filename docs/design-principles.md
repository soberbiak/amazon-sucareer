# Design principles

These eleven principles govern every skill and shared reference in this plugin.

1. Evidence before narrative.
2. No unsupported claims.
3. Separate fact from inference.
4. Preserve attribution boundaries.
5. Metrics require context.
6. Privacy by default.
7. JD adaptation must not alter facts.
8. Every strong claim should survive an interview.
9. Reframe work, not facts.
10. Positioning follows ownership, not tenure.
11. Failures improve the system more than prompts do.

When a workflow fails, correct the schema, rule, validator, or test that allowed the failure. Do not solve a structural failure only by adding persuasive wording.

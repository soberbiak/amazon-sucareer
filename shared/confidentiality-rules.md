# Confidentiality rules

Apply privacy by default.

- `public_safe`: safe to state as written.
- `generalize`: preserve meaning while removing or coarsening sensitive identifiers, scale, or precision with the user's approval.
- `private_only`: retain for private reasoning but exclude from public resumes, examples, and repository files.

Never put real personal names, employers, stores, brands, product identifiers, supplier identifiers, commercial figures, local paths, or conversation traces into reusable fixtures. Public examples must be synthetic by construction, not lightly anonymized versions of private material.

Generalization must preserve truth. Do not replace an exact confidential result with an invented approximate result. Prefer a truthful band, direction, or scoped description when the user authorizes it.

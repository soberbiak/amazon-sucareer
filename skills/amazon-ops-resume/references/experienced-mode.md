# Experienced-hire mode

Experienced resumes demonstrate judgment under real constraints. Calibrate the proof standard with [experience-levels.md](experience-levels.md).

## Recommended order

1. name, target level, contact/location;
2. three-line executive summary with total scope and differentiators;
3. core capabilities grouped by business mechanism, not software list;
4. work experience with projectized sub-themes;
5. selected high-complexity projects if they add non-duplicative evidence;
6. education and certifications.

## Projectization pattern

Transform ordinary responsibility into a defensible operating case while keeping the candidate at the center:

```text
Target identity → business scope → key conflict → owned judgment → mechanism → influence and execution → business result
```

Not every bullet needs every element. Across a role, however, the reader should see the full chain. Keep detailed team dependencies in the evidence ledger; include them in resume copy only when omitting them would create a false ownership claim.

## Mechanisms worth surfacing

- portfolio segmentation and resource allocation;
- launch or lifecycle operating cadence;
- keyword and traffic structure;
- advertising governance and budget rules;
- inventory forecasting, replenishment, and aging controls;
- profitability monitoring and fee/cost diagnosis;
- review/VOC analysis and product feedback loops;
- cross-functional escalation and operating reviews;
- dashboards, SOPs, experiments, or exception alerts.

Only include a mechanism if the candidate actually used it and can explain how decisions changed because of it.

## Attribution-aware verbs

- Use “主导 / 牵头 / 负责 / 搭建 / 制定” for owned decisions or mechanisms.
- Use “推动 / 统筹 / 落地 / 闭环” when the candidate mobilized other roles or resources.
- For shared outcomes, lead with the candidate's owned mechanism, then state the business result; do not weaken every bullet with generic disclaimers.
- Use “参与 / 支持” only when the candidate truly lacked meaningful ownership.
- Use “与……同期 / 关联” when evidence does not support causation.

Apply **maximum defensible ownership**: select the strongest wording the candidate can explain with decisions, actions, evidence, and boundaries in an interview. Never upgrade tenure alone into team leadership, P&L ownership, or full-chain control.

## Compression rule

Keep the strongest one or two cases for each competency. Delete repeated “日常运营、优化 Listing、投放广告” lines once a stronger mechanism-and-result bullet proves the same skill.
